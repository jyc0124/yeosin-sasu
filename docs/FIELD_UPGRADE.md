## 2. 무엇을 바꿨나 (구조 — 문항별 수정 아님)
1. **기준 질문(Q) = 근거 조회 + 원문 대조 검증**(`lib/basis`, `data/kb/tags.json`): 고정 주제 목록에 없는 해석형 질문용. 코드가 규제×개념 태그로 근거를 고르고 → Router가 그 근거로만 문장 → 문장마다 원문 대조 → 판정 코드는 코드가(모두 확인 '안내' / 일부 미확인 '보류'). 근거가 없으면 LLM 없이 보류. 고객 건 허용·불허는 내지 않음.
2. **판정 근거 자료 원문 대조**: Codex가 사실 51개를 원문과 대조 → 빠진 단서 16건, 전부 원문으로 확인 후 반영(예: F828-01 "**대출금액을** 증액", F401-01 "처분조건부(**주담대 실행 시 약정 체결**)", F401-07 등록임대 종료일은 **의무임대기간 종료일 기준**). 행정지도에 있던 규정 추가: 유주택자 전세대출 한도 2억원(F828-09·10), 1주택자 전세대출 DSR(F828-11·12), HOMS 동의(F828-08). 새 쟁점 G-14(보증기관 주택 수 가족 범위)·G-15(증액 대환 분류) — Liner 조사 결과 공식 근거 없음.
