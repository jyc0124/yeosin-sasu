# 화면 디자인 기준

2026-11-16 정리. 참고: liner.com 공개 소개 페이지(앱은 로그인 필요라 보지 않음), Mobbin의 Perplexity·Linear·Vercel·Mercury 화면.

## 방향

**Liner의 화면 문법을 따르되, 우리 제품의 이름·색은 유지한다.** 심사위원(Liner)에게 "Liner 위에서 자연스럽게 확장한 업무 도구"로 읽히게 하되, Liner 제품으로 오인되지 않게 한다.

## 따라갈 것 (Liner에서 확인한 패턴)

| Liner 패턴 | 우리 화면 적용 |
|---|---|
| 문장 끝 작은 **인용 번호**, 문장에 마우스를 올리면 연한 형광 하이라이트 | 결론·조건·고객 안내 문장 끝에 근거 번호(F813-01 → ①). 누르면 오른쪽 근거 패널의 해당 원문으로 이동·강조 |
| 인용 팝오버 **"인용된 출처 / 이 출처가 왜 사용되었나요?"** | 근거 카드에 "이 근거가 쓰인 이유" — 규칙 엔진 판정 경로(S1~S6)에서 그 Fact를 쓴 단계 문장을 보여 줌 |
| 처리 줄 **"검색 완료 / 웹 문서 77개", "읽음 forbes.com"** | 처리 단계 줄 문구를 같은 형식으로("조건 읽기 완료 / 항목 6개", "원문 대조 / 근거 4개") |
| 둥근 알약형 입력창, 왼쪽 + 버튼, 오른쪽 전송 원형 버튼 | 입력창 모서리·전송 버튼 모양 |
| "관련 질문으로 더 깊게" | 역질문 아래 "자주 이어지는 확인" 대신 기존 역질문 번호 목록 유지(새 기능 추가 안 함) |
| 넉넉한 여백, 큰 제목 + 회색 보조 문장, 출처 강조 | 이미 반영(글자 16px 기준) |

## 피할 것

- Liner 로고·워드마크·"Liner" 제품명을 우리 제품 이름처럼 쓰기. "Liner Router·Search로 찾음"처럼 **사용한 API 표기**로만 쓴다.
- Liner 브랜드 초록을 주 색으로 쓰기 → 사칭처럼 보임. 우리 강조색은 남색 유지. 초록은 판정 '허용'과 처리 완료 체크에만.
- 마케팅 페이지의 일러스트(점묘 손 그림) 모방.

## 색 규칙 (현재 구현)

- 남색(indigo): 우리 제품의 주요 동작 — 판정 버튼, 선택 메뉴, 질문 말풍선, Liner가 찾은 후속 문서 표시
- 판정 색: 허용 초록 · 조건부 파랑 · 불허 빨강 · 심사위 보라 · 보류 호박 · 역질문 주황 · 내부지침 회색. 판정 결과에만 쓴다
- 형광 밑줄: 결론 문장 속 날짜·금액·기간에만

## 화면별 다음 작업

- 창구 판정: 인용 번호 ↔ 근거 패널 연결, "이 근거가 쓰인 이유"
- 정책 감시: Vercel 배포 요약 카드(문서명 · ● 원문 해시 일치 · 발견 출처 · 조항 대조 18/18) + 6단계 체크리스트, KB v2 = 현재 적용, v1 되돌리기 = 롤백
- 본점 질의: Mercury 진행 타임라인(지점 접수 → 본점 검토(회신 기한) → [외부기관 문의, 필요한 건만] → 승인·FAQ 등록). 외부기관 단계는 sky 색
- 평가 결과: 큰 수치 카드 유지, 표를 카드형으로 정리
