## 말할 때 지킬 것 (PITCH.md 요약)

- "통계적으로 유의하다", "몇 % 시간 단축" 금지(재지 않음). 평가는 팀이 만든 문항, 세트당 1회.
- Liner 기여는 **6가지 일**(조건 추출·안내 문구·정책 감시·해석 쟁점 조사·현장 질문 근거 조사·빠른 반응). 정확도 자체는 규칙 엔진 덕.
- Liner 비교는 "**고객 질문만으로** 그 문서를 찾아온 것은 Liner"로 말한다. "Liner만 찾는다"는 금지(문서 이름을 넣으면 ChatGPT도 찾음). 근거 `data/compare/search_1122/RESULT.md`.
- 10.20 인구감소지역 재지정은 Liner 최초 발견이 아님 — 영상에서 언급하지 않거나 "확인"으로만.
- '자동 상정' 금지 → "상정 결정 이후의 안건 등록·일정·통보를 에이전트가 맡는다".
- 베타 테스트 결과를 넣는다면 "현직 시중은행 직원 N명" — 은행명·내부 규정 금지.
