## 범위 조정 규칙 (일정이 밀리면)
1. 먼저 줄이는 것: F3 → "질의서 생성 + 승인 버튼"만 남기고 FAQ 재사용은 뺍니다.
2. 그다음: F2 원문 추출 → 8.28 행정지도는 미리 추출해 두고, 감시는 **실제 Liner 발견까지만** 실시간으로 보여 줍니다.
3. 절대 줄이지 않는 것: **F1 판정 정확도**, **타임머신 장면**, **A/B 수치**. 이 세 가지가 심사 점수의 핵심입니다.
