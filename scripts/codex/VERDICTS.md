# 답변 코드 (질문 하나에 하나)
- 허용: 규제 대상이 아니거나 예외가 확정돼 진행 가능
- 조건부: 조건(기간·증빙·증액하지 않음 등)을 지키면 가능
- 불허: 원칙적 제한에 해당하고 확인된 예외 없음
- 심사위: 금융회사 여신심사위원회가 판단할 사항(지점 확답 불가)
- 내부지침: 금융회사 내부 기준에 맡겨진 사항
- 보류: 정부 발표 자료에 답이 없어 확정 불가(본점 확인 필요)
- 역질문: 판정에 필요한 사실이 빠져 고객에게 먼저 물어야 함
- 안내: 특정 고객 건 판정이 아니라 정부 자료로 확인된 기준(정의·기준일·적용 범위)을 알려 주는 답
- OUT: 8.13 비거주 1주택자 전세대출 제한, 4.1 다주택자 주담대 만기연장 제한, 그리고 같은 8.28 행정지도의 전세대출 한도·1주택자 전세대출 DSR과 무관한 질문(보증기관별 서류·실무 등)
