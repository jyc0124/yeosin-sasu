# B01-run0 · ChatGPT 원문 (사용자 실행분)

- 일시: 2026-11-16, 사용자가 직접 실행해 대화창에 붙여 넣은 답변(같은 질문의 다른 회차). 출처 아이콘 이미지 링크는 뺐다.

## 질문

내년 2월 전세 만기 손님이에요. 서울 아파트 분양받고 한 번도 안 살고 바로 전세 줬대요. 본인은 경기도 전세 살고요. 연장 돼요?

## 답변

**결론부터 말씀드리면, 이 고객은 2027년 2월 전세자금대출 만기연장이 원칙적으로 어렵습니다.** 다만 예외 사유가 있으면 연장이 가능할 수 있습니다.

2026년 11월 16일 기준, 금융위원회가 발표한 8·13 부동산 금융대책을 적용한 판단입니다.

### **1. 고객 상황에 대한 판단**

| 확인 항목      | 고객 상황          | 판단                   |
| ---------- | -------------- | -------------------- |
| 주택 보유      | 서울 아파트 분양 후 소유 | 규제 대상                |
| 해당 아파트 실거주 | 입주한 적 없음       | 규제 대상                |
| 해당 아파트 임대  | 바로 전세를 줌       | 규제 대상                |
| 현재 거주      | 경기도 전세         | 전세대출 이용 여부 확인        |
| 대출 연장 시점   | 2027년 2월       | 2027년 1월 1일 시행 규정 적용 |

금융위원회는 **수도권·규제지역 아파트를 소유하면서 타인에게 임대하고, 본인과 배우자 모두 실거주 이력이 없는 1주택자**에 대해 전세대출 신규 취급과 만기연장을 제한하기로 했습니다. (대한민국 정책브리핑)

특히 이번 고객처럼 **분양받은 아파트에 한 번도 살지 않고 바로 전세를 준 경우**는 이 규제에 해당할 가능성이 높습니다.

### **2. 예외적으로 연장할 수 있는 경우**

| 예외 사유                           | 연장 가능성              |
| ------------------------------- | ------------------- |
| 세입자가 있는 집을 매수하면서 기존 임대차계약을 승계   | 기존 계약 종료일까지 가능      |
| 본인이 거주하는 전셋집의 임대인이 보증금을 반환하지 못함 | 예외 허용               |
| 퇴거 예정이나 이사 일정이 맞지 않음            | 단기 연장 가능(예: 6개월 이내) |
| 실거주하지 못한 불가피한 사유를 여신심사위원회가 인정   | 심사 후 가능             |

단, **분양받은 새 아파트를 직접 전세 놓은 것은 기존 세입자의 계약을 승계한 경우와 다릅니다.** 이 사유만으로 예외를 적용하기는 어렵습니다. (금융위원회)

### **3. 은행 창구에서 추가 확인할 사항**

고객에게 다음 세 가지를 확인하면 됩니다.

1. 경기도 전셋집에 **현재 전세자금대출을 이용 중인지**, 그리고 2027년 2월이 대출 만기인지
2. 서울 아파트를 처음부터 전세 준 이유가 무엇인지, 본인 또는 배우자의 실거주 이력이 정말 없는지
3. 경기도 전셋집에서 계속 거주하려는 것인지, 서울 아파트에 입주할 계획이 있는지
