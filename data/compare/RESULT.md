## 해석

- (조건 정정 11/22: 검색 버튼은 끈 일반 채팅, ChatGPT가 스스로 웹을 검색해 출처를 붙임) 최신 ChatGPT는 **FAQ에 답이 그대로 있는 문항**(B01-a~c, B12, A02)은 잘 맞힌다. 우리 평가표의 "LLM 단독 15.6%"는 검색 없는 조건이라, 심사위원이 ChatGPT를 직접 써 보면 체감 차이는 그보다 작다.
- 차이는 세 군데에서 난다.
  1. **후속 문서(8.28 행정지도)**: B02 증액 조건, C07 경과조치 기준. Liner 정책 감시로 들어온 근거라 ChatGPT 검색으로는 안 잡혔다.
  2. **원문에 없는 것을 단정하지 않음**: C02. ChatGPT는 그럴듯한 유추로 결론을 낸다.
  3. **지점 권한의 경계**: C05 심사위, C07 회피 비안내. ChatGPT는 "네"로 시작하거나 회피 경로를 후속 질문으로 제안한다.
- 영상·기획서에는 C07과 B02를 나란히 보여 주는 게 가장 설득력 있다.

## 원문 파일

- ChatGPT: `data/compare/chatgpt/<ID>.md` — 답변의 '복사' 버튼으로 받은 원문(마크다운, 출처 링크 포함)과 대화 주소. `B01-run0.md`는 사용자가 따로 실행한 같은 질문의 다른 회차.
- 코파일럿: `data/compare/agent/<ID>.md`(조건·판정·근거 원문·판정 경로) + `<ID>.ndjson`(API 응답 스트림 원본). 저장 시 재요청이라 서버 캐시로 0.3초. 처음 실행 시간은 `agent.json`의 `sec`.
- 채점: `data/compare/compare.json` → `npm run eval:report`가 `/eval` 화면과 docs/EVAL.md ⑤ 섹션에 반영.
- 추가 관찰: ChatGPT는 B01-a(불허) 답변 끝에도 "12월에 미리 연장 신청하면 가능할까?"를 후속 질문으로 제안했다. C07과 같은 회피 방향.
