# A02 · 에이전트 원문

- 일시: 2026-11-16, 배포 주소 /api/judge, KB v2, 기준일 2026-11-16, 조건 추출 모델 liner-gpt-router
- 원본 스트림: `A02.ndjson`

## 질문

다주택 고객인데 세입자 계약이 26.6.30 종료였고 5/10에 2년 재계약했대요. 만기 12월인데 재계약 기준으로 연장 되나요?

## 질문에서 읽은 조건

```json
{
 "module": "M2",
 "houseCount": 2,
 "houseCountIsMinimum": true,
 "maturityDate": "2026-12-15",
 "tenant": {
  "contractValidAt0401": true,
  "originalEnd": "2026-06-30",
  "renewalDate": "2026-05-10",
  "renewedEnd": "2028-06-30"
 },
 "asOf": "2026-11-16"
}
```

가정: 가계약 언급 없어 4.1 기준 유효 계약으로 가정 / 2년 재계약 → 기존 계약 종료일 2026-06-30에 2년을 더해 갱신계약 종료일을 2028-06-30로 가정 / 만기 12월 → 2026-12-15로 가정

## 판정: 역질문

**갱신청구권 행사면 갱신계약 종료일(28.6.30)까지, 합의 재계약이면 기존 종료일(26.6.30)까지만 인정됩니다.**

### 조건·주의

- 담보가 수도권·규제지역 아파트인 경우를 전제로 한 판정입니다.

### 고객에게 확인할 것

- 세입자가 계약갱신청구권을 행사한 것인가요, 아니면 합의로 재계약한 것인가요? (묵시적 갱신이라면 갱신일은?)

### 필요 서류

- 임대차계약서(갱신계약서 포함)

### 근거 원문

- **F401-01** (401본 2-(1), 401FAQ Ⅲ-1) 대상: 주택(소재지 무관) 2채 이상 보유 개인, 임대사업자(개인·법인). 처분조건부 1주택자 제외. 개인·개인 임대사업자는 세대 기준으로 판단
- **F401-02** (401본 2-(2)) 원칙: 다주택자가 보유한 수도권·규제지역 APT 주담대 만기연장 원칙 불허 (신규취급은 이미 제한 중)
- **F401-12** (401본 2-(3)) 시행 시기: 4.17 이후 만기 도래 건에 시행. 4.16까지 만기 도래 건은 종전 규정. 만기는 4.1 기준 유효한 대출약정서상 만기 기준
- **F401-06** (401본, 401FAQ Ⅲ-6) 예외① 임차인이 있는 경우 → 임대차계약종료일까지. 종료일 정의: (원칙) 4.1 기준 유효하게 체결된 계약의 종료일(기존 임차인 연장계약·묵시적 갱신 포함 → 연장계약 종료일, 후속 임차인 신규계약 → 신규계약 종료일) / (예외) 4.2~4.16 묵시적 갱신, 4.1부터 4개월 내(7.31까지) 종료되는 계약의 갱신청구권 행사 → 갱신계약 종료일 / 그 외 4.2 이후 갱신 → 기존 계약 종료일까지만. 가계약 미인정

### 판정 경로 (규칙 엔진)

- T2 주택 수 — 세대 기준 2채 → 다주택자 [F401-01]
- T3 담보 — 수도권·규제지역 아파트 담보(또는 전제) [F401-02]
- T4 시행 시기 — 만기 26.12.15 → '26.4.17 이후 만기, 제한 적용 [F401-12]
- T5 예외① 임차인 — 갱신 방식에 따라 인정 종료일이 달라짐 [F401-06]
