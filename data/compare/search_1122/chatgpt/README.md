# ChatGPT 웹 검색 결과 (2026-11-22, 사용자 실행)

- 조건: 새 채팅마다 문장 하나, 🌐 웹 검색 켬, 추론 설정 High, 문장 그대로 입력. 답변의 복사 버튼으로 받은 원문.
- 답변 속 사용자 개인 프로젝트 이름(ChatGPT 메모리에서 온 것)은 [사용자 프로젝트]로 가렸다.
- 참고: 11/16 대조(data/compare/chatgpt/)는 웹 검색 버튼을 켜지 않은 일반 채팅(필요할 때 ChatGPT가 스스로 검색)으로, 창구 질문을 넣어 최종 답을 본 것이다. 이번은 같은 검색어 6개로 '문서를 찾는가'와 답의 핵심 내용을 본다.
